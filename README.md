## FileHub v1.0.0 

**FileHub: Instant Search & Preview across Private Cloud**

The initial release of FileHub, designed for high-performance file management and cross-platform accessibility.

---

### ■ Key Features
* **Lightning-Fast File Search:** Powered by a **Trie index** supporting String, Fuzzy, and Regex queries.
* **Inline Previews:** Instant viewing for **Markdown, PDF, Excel, ZIP, Images, and Video**.
* **Power-User UI:** Sleek **Dark Theme** with **Vim-like keyboard navigation** for maximum efficiency.
* **Streamlined Workflow:** Integrated **Tab management** and native **Terminal synchronization**.
* **Flexible Configuration:** Simple management of directories and rules via **YAML settings** (`~/.filehub`).
* **LAN Sharing:** Built-in mode for seamless file sharing across your local network.
